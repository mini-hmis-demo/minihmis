# Security policy

**MiniHMIS is a demo project.** It is fake software used to demonstrate a
security pre-disclosure workflow. Advisories published in this repository are
part of that demonstration; no CVEs are requested for them.

## Supported versions

Only the two most recent minor releases receive security fixes.

| Version | Supported |
| --- | --- |
| 1.3 | Yes |
| 1.0 | No - upgrade required |

## Reporting a vulnerability

Use GitHub's **Report a vulnerability** button under the Security tab
(private vulnerability reporting). Please do not open a public issue.
